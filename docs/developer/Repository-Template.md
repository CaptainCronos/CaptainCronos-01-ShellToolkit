# ShellToolkit Layout Reference

This document is retained only to redirect an older documentation entry. It is
not a canonical template for future Captain Cronos repositories.

Ecosystem-wide repository organization and lifecycle requirements are governed
by these Engineering Manual documents:

- `07-Standards/Directory-Structure.md`
- `02-Git/Repository-Lifecycle.md`

ShellToolkit's own implemented layout is documented in
[`Repository-Layout.md`](Repository-Layout.md). Its `tools/commands/`, `lib/`,
`bash/`, `baseline/`, `defaults/`, installation, and validation paths reflect
this toolkit's responsibilities and must not be imposed on unrelated projects.
